# Specification Readiness Checklist

**Status:** Not yet ready for implementation.

## Source and behavior
- [ ] Original workbook inspected in full.
- [ ] All relevant formulas, factors, assumptions, units, and rounding rules documented.
- [ ] Existing Apps Script behavior mapped.
- [ ] Known-answer cases captured from the workbook.
- [ ] Methodology concerns separated from software defects.

## User experience
- [ ] User flow and required fields documented.
- [ ] Labels, units, help text, defaults, and validation rules documented.
- [ ] Success, failure, loading, and retry states defined.
- [ ] Report format and contents approved.

## Data and security
- [ ] Submission schema approved.
- [ ] Calculation-detail schema approved.
- [ ] Unique ID and duplicate-request strategy defined.
- [ ] Concurrent write and partial failure behavior defined.
- [ ] Public/private access boundary reviewed.
- [ ] Personal data necessity and retention policy reviewed.
- [ ] Abuse controls and Apps Script quota risks addressed.

## Delivery
- [ ] Testable acceptance criteria complete.
- [ ] Technical plan reviewed.
- [ ] Owner approves specification and implementation scope.
