# MVP Readiness Checklist

- [x] Workbook formulas and cached outputs inspected.
- [x] Existing behavior characterized with a known-answer test.
- [x] Calculation and UI separated.
- [x] User inputs limited to values that affect current workbook outputs.
- [x] No database or central submission storage.
- [x] Downloadable result includes assumptions and limitations.
- [x] Automated tests pass locally.
- [ ] Streamlit Cloud deployment and browser smoke test.
- [ ] Owner reviews methodology limitations before public use.
